# はじめに

みなさん、こんにちは！今回は**Google Authenticator**について解説していきます。

「名前は聞いたことあるけど、よくわからない...」
「QRコード読み取って数字が出てくるやつでしょ？」

そんな方も多いのではないでしょうか。この記事では、Google Authenticatorの基本から仕組みまで、できるだけわかりやすく説明していきます！

## Google Authenticatorって何？

Google Authenticatorは、**2段階認証（2FA: Two-Factor Authentication）** を行うためのスマホアプリです。

簡単に言うと、「パスワードだけじゃなくて、もう1つ別の方法で本人確認をしよう！」というセキュリティ対策のためのツールなんですね。

### なぜ2段階認証が必要なの？

想像してみてください。もしパスワードが流出したら...😱

- 不正ログインされる
- 個人情報が盗まれる
- アカウントを乗っ取られる

こんな恐ろしいことが起きてしまいます。

でも、2段階認証があれば、たとえパスワードが漏れても、**もう1つの認証要素**がないとログインできません。これがセキュリティを大幅に強化してくれるんです！

## Google Authenticatorの使い方

まずは基本的な使い方を見てみましょう。

### 1. アプリをダウンロード

iOS・Androidどちらでも無料でダウンロードできます。

### 2. サービスと連携

対応しているサービス（GitHub、AWS、Googleアカウントなど）で2段階認証を設定すると、QRコードが表示されます。

### 3. QRコードを読み取る

Google AuthenticatorアプリでそのQRコードをスキャンすると...

### 4. 6桁の数字が表示される

**30秒ごとに変わる6桁の数字**が表示されます。この数字を入力することでログインできます！

## どんな仕組みで動いているの？

ここからが本題です。「なんで30秒ごとに数字が変わるの？」「どうやって本人確認してるの？」という疑問に答えていきます。

### TOTP（Time-based One-Time Password）という技術

Google Authenticatorは**TOTP**という技術を使っています。日本語にすると「時間ベースのワンタイムパスワード」です。

名前の通り、**時間**を使ってパスワードを生成する仕組みなんですね。

### 仕組みの概要

以下の要素を組み合わせて、6桁の数字を作り出しています：

1. **シークレットキー**（QRコードに含まれている秘密の情報）
2. **現在時刻**（30秒単位）
3. **HMAC-SHA1**という暗号化アルゴリズム

```
ワンタイムパスワード = TOTP(シークレットキー, 現在時刻)
```

### もう少し詳しく見てみよう

#### ステップ1: シークレットキーの共有

最初にQRコードを読み取った時、実は**シークレットキー**というランダムな文字列が、サービス側とアプリの両方に保存されます。

```
例: JBSWY3DPEHPK3PXP
```

このシークレットキーは、サービス側とあなたのスマホだけが知っている「秘密の合言葉」みたいなものです。

#### ステップ2: 時刻を30秒単位に丸める

現在のUnixタイムスタンプ（1970年1月1日からの秒数）を30で割ります。

```
タイムステップ = 現在のUnixタイムスタンプ ÷ 30
```

例えば：
- 2024年1月1日 12:00:00 → タイムステップ: 57283200
- 2024年1月1日 12:00:29 → タイムステップ: 57283200（同じ）
- 2024年1月1日 12:00:30 → タイムステップ: 57283201（変わる！）

これで30秒ごとに数字が変わる理由がわかりましたね！

#### ステップ3: HMAC-SHA1で暗号化

シークレットキーとタイムステップを使って、HMAC-SHA1というアルゴリズムで計算します。

```
ハッシュ値 = HMAC-SHA1(シークレットキー, タイムステップ)
```

この計算結果から6桁の数字を取り出します。

#### ステップ4: 6桁の数字を表示

最後に、計算結果から6桁の数字を抽出して表示します。

```
123456
```

### サービス側も同じ計算をしている

重要なポイントは、**サービス側も全く同じ計算をしている**ということです。

1. サービス側はシークレットキーを持っている✅
2. サービス側も現在時刻がわかる✅
3. 同じアルゴリズムで計算する✅

だから、あなたが入力した6桁の数字と、サービス側が計算した数字が**一致すれば本人確認完了**となるわけです！

## なぜ安全なの？

### オフラインで動く

Google Authenticatorは**インターネット接続不要**で動きます。スマホ内で計算が完結するので、通信を傍受されても安全です。

### 30秒で無効になる

パスワードが30秒ごとに変わるので、たとえ誰かに見られても、すぐに使えなくなります。

### シークレットキーは外部に出ない

シークレットキーはスマホとサービス側にしか保存されていません。QRコード読み取り後は、インターネットに送信されることはありません。

### 推測が不可能

暗号化アルゴリズム（HMAC-SHA1）により、シークレットキーを知らない人が次の数字を予測することは事実上不可能です。

## 他のワンタイムパスワードとの違い

### SMSとの違い

SMSで届くコードも2段階認証ですが、違いがあります：

| 方式 | メリット | デメリット |
|------|---------|-----------|
| SMS | 設定が簡単 | SIMスワップ攻撃のリスク、電波が必要 |
| Google Authenticator | オフライン動作、より安全 | スマホ紛失時のリスク |

### 他の認証アプリとの違い

実は、Google Authenticator以外にも似たアプリがたくさんあります：

- Microsoft Authenticator
- Authy
- 1Password
- Bitwarden

これらは基本的に**同じTOTP規格**を使っているので、互換性があります。Google Authenticatorでなくても使えることが多いです！

## 注意点

### バックアップを忘れずに！

スマホを紛失したり、機種変更する時のために、**バックアップコード**や**QRコードのスクリーンショット**を安全な場所に保存しておきましょう。

### 時刻のズレに注意

スマホの時刻が大幅にズレていると、正しいコードが生成されません。自動時刻設定をONにしておくことをおすすめします。

### 複数デバイスで登録できる

同じQRコードを複数のデバイスで読み取れば、複数のスマホで同じコードを生成できます。バックアップとして便利です。

## まとめ

Google Authenticatorは、時間とシークレットキーを使って30秒ごとに変わる6桁の数字を生成する、シンプルでありながら強力なセキュリティツールです。

**ポイントのおさらい：**

✅ 2段階認証でセキュリティを大幅強化
✅ TOTPという時間ベースの仕組みを使用
✅ オフラインで動作するから安全
✅ シークレットキー + 現在時刻で計算
✅ 30秒ごとに新しいコードを生成

パスワードだけでは不安な時代です。まだ使っていない方は、ぜひGoogle Authenticatorを導入してみてください！

セキュリティは面倒に感じるかもしれませんが、一度設定すれば、あとは数字を入力するだけ。この小さな手間が、あなたのアカウントを守ってくれますよ 👍
